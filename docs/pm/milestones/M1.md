# M1 — Profiles, worlds, and project persistence

**Goal:** Local profiles, worlds and full project management (create, rename, archive, trash) that persist offline, with no canvas interaction and no model connection. (Spec §23 M1)
**Exit:** Useful local project management without any canvas interaction or model connection.
**Status:** ⏳ Planned 2026-11-11 · **GitHub milestone:** M1 · 11 issues (#20, #29–#38)

**Out of scope (on purpose):**
- Import inspection: moved to `IMP-1` (ROADMAP change #2).
- Permanent delete: archive + recoverable trash only (PRD §5.6 allows this).
- A durable `events` table: the renderer re-fetches after each command. Events come with the runtime (M3/M4).
- World canvas placement: M2.

**Capacity:** about 15% is held back for review findings (M0 retrospective: 2 of 10 issues were unplanned).
