# M0 — Foundation and risk spikes

**Goal:** Prove the desktop stack can be packaged before building the product on it. (Spec §23 M0)
**Exit:** A packaged app opens offline and shows persisted sample data. No AI calls, no marketplace, no user file access.
**Status:** 🔨 In progress (M0-1 in review) · **GitHub milestone:** M0

## Decisions to make at the start (each → AskUserQuestion → ADR)
| Decision | Options to compare | When |
|---|---|---|
| Package manager | pnpm (spec default, via corepack) vs npm | M0-1 |
| Electron build tooling | electron-vite + electron-builder vs Electron Forge | M0-1/M0-2 |
| SQLite binding | better-sqlite3 vs built-in `node:sqlite` (check Electron's bundled Node version) | M0-3 |
| Project license | MIT / Apache-2.0 / proprietary-for-now | M0-1 |
| E2E tooling | Playwright `_electron` | M0-2 |
