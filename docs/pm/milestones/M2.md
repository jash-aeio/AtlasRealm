# M2 — Isometric world, placement, hotbar, library and Atlas shell

**Goal:** The fantasy isometric world shows the real saved projects as buildings. You can place, move and remove them (with undo), pin them to a ten-slot hotbar, find everything in a searchable library, and see geography (Map) and typed project links (Connections) in the upper-right Realm Atlas. (Spec §23 M2)
**Exit:** The world accurately represents saved projects and can grow beyond ten projects.
**Status:** ⏳ Planned 2026-11-20 · **GitHub milestone:** M2 · 21 issues (15 new: #66–#80; 6 follow-ups: #56–#60, #62)

**Out of scope (on purpose):**
- Import inspection `IMP-1`: moved to M3, next to `IMP-2 commit` (user choice 2026-11-20). M2 only makes sure unplaced projects are first-class, which is what imported projects will need.
- Placing service structures (Guild, shops) on the map: the schema allows it (`service kind`), but M2 only offers sidebar entrances (spec Build list).
- Project workspace tabs and interiors: M5. "Open" shows the project details and summary.
- Real building art: placeholders only (ADR-0013). Production art comes later (ART_BIBLE §34).
- L4 read caps: issue #61 in M3, gated before imports and restore.

**Capacity:** 21 issues is about twice M1's 11. About 15% is still held back for review findings. If M2 runs long, M2-14 (comfort) and #58 (CSP tidy-up) can slip to M3 without breaking an M2 Check.
