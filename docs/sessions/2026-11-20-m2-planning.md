## Decisions (via AskUserQuestion)
- **Archiving or trashing a project removes its building** in the same step, so the project becomes unplaced. Restore leaves it unplaced, and hotbar pins stay and show the status. Why: no "ghost" buildings block tiles, and it follows the rule that removing a representation never deletes a project.
- **Follow-ups:** name/goal hardening (#60), the archived-world guard (#59) and the profile security notice (#62) are in M2. L4 read caps (#61) stay in M3. The same-millisecond world tie-breaker is dropped on purpose.
- **IMP-1 (import inspection)** moves into M3, next to IMP-2 (the commit step). Inspection alone isn't useful to a user yet.
- Routine (no question asked): hotbar targets are projects and sidebar services. Undo history lives in memory and is cleared on a world or profile switch. Comfort preferences use the existing profile preferences, so there is no schema change. "Open" shows the project details until the workspace arrives in M5.
