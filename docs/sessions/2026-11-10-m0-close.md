## Retrospective
**Went well**
- Every big stack risk (packaging, native SQLite, sandboxed IPC, Pixi + React Flow sharing state, the worker process) was proven by a test, not by a claim.
- Per-PR security reviews found real problems early (the `file://` login-hash leak route → M0-9; Chromium switches → #20).
- The packaged smoke test runs in CI, so packaging breakage shows up on every PR.

**Didn't go well**
- Scope grew: 2 of 10 issues weren't in the original plan.
- Status docs fell behind the merges (status still said M0-8 was "in review" after it merged).
- Running pnpm only through corepack caused friction (electron-builder needed temporary shims).

**Change next time**
- Leave about 10–20% of each milestone for review findings.
- Run `/sync-pm` right after each merge, not at the end.
- Plan M1 with #20 near the start, so the security gate isn't left until the last moment.
