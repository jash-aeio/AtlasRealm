# ADR-0005: Approved product decisions of November 6, 2026

- **Status:** Accepted. Do not reopen without new evidence (spec §26).
- **Date:** 2026-11-06

## Decisions
1. Name **Atlas Realm**; full title *Atlas Realm: An Agentic AI Ecosystem*.
2. Upper-right, context-sensitive **Realm Atlas** with **Map** and **Connections** tabs (§30).
3. **2.5D enterable cutaway interiors with Blueprint mode** before any true 3D (§31).
4. **Optional Obsidian O1** (export/open) before O2 indexing and O3 two-way edits (§32).
5. **Reviewed automatic setup for existing folders** with copy/link choices (§33).
6. **PixelLab MCP** preferred for producing a locally packaged fantasy asset set (§34; see ADR-0006).

## Consequences
These are requirements for planning. Changing one needs a new ADR that supersedes this one.
